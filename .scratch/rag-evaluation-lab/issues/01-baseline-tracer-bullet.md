# 01 — Baseline tracer bullet

**What to build:** Make one tiny policy question travel through the evaluation runner, become a saved result, and appear in a minimal Streamlit view. This establishes the complete path and the single testing seam before the experiment grows.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] A tiny deterministic benchmark containing one policy section and one answerable question runs without network access or paid services.
- [ ] The evaluation runner returns a structured result containing the question, expected section, retrieved evidence, and whether retrieval hit the expected section.
- [ ] The result can be saved, loaded again, and displayed in a minimal Streamlit view.
- [ ] One automated test exercises the complete behavior through the evaluation runner interface.
- [ ] The project has only the dependencies and local run instructions needed for this slice.
